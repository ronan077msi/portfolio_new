# Portfolio Ronan77

Portfolio statique de Ronan Andriamahenitsoa, développeur web et webmarketeur freelance.

## Lancer le site

Aucune installation n'est nécessaire. Ouvrez `index.html` dans un navigateur moderne, ou servez ce dossier avec un serveur web statique.

## Structure

- `index.html` : contenu et structure de la page.
- `assets/css/style.css` : styles, responsive design et animations.
- `assets/js/script.js` : interactions, navigation, préchargeur, AOS et barres de progression.
- `assets/img/` : images du site.

## Dépendances CDN

Le site charge Bootstrap, Bootstrap Icons, Font Awesome et AOS depuis des CDN. Une connexion Internet est nécessaire pour afficher ces bibliothèques lors d'une ouverture locale.

## Accessibilité et animations

Les animations respectent la préférence système `prefers-reduced-motion`. Les cartes de contact sont animées à leur entrée dans la zone visible via AOS.

## Rapports

Les changements récents sont documentés dans `rapport-modifications.yaml` et `RAPPORT_MODIFICATIONS.txt`.
